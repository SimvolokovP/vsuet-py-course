## Проверки

| Программа                                     | Вход                     | Ожидаемый ответ                                                                       | Фактический ответ |
| --------------------------------------------- | ------------------------ | ------------------------------------------------------------------------------------- | ----------------- |
| `statistics.py`                               | `-2 0 5 3`               | количество `4`, сумма `6`, минимум `-2`, максимум `5`, среднее `1.50`                 | совпадает         |
| `statistics.py`                               | `8`                      | количество `1`, сумма `8`, минимум `8`, максимум `8`, среднее `8.00`                  | совпадает         |
| `statistics.py`                               | пустой ввод              | `Нет данных`                                                                          | совпадает         |
| `transform.py`                                | `-2 0 5 -2`              | исходный `[-2, 0, 5, -2]`, новый `[2, 0, 5, 2]`                                       | совпадает         |
| `transform.py`                                | пустой ввод              | исходный `[]`, новый `[]`                                                             | совпадает         |
| `positions.py`                                | `7 7`                    | `[0, 1]`                                                                              | совпадает         |
| `positions.py`                                | `-3 -1 -2`               | `[1]`                                                                                 | совпадает         |
| `positions.py`                                | `3 7 2 7`                | `[1, 3]`                                                                              | совпадает         |
| `positions.py`                                | пустой ввод              | `Нет данных`                                                                          | совпадает         |
| `variant.py` (вариант 2: отрицательные числа) | `-8 -3 0 6 6 1`          | `[-8, -3]`, количество `2`, сумма `-11`, отсортированная `[-8, -3]`                   | совпадает         |
| `variant.py`                                  | `-2 5 -10 -3 0 -2`       | `[-2, -10, -3, -2]`, количество `4`, сумма `-17`, отсортированная `[-10, -3, -2, -2]` | совпадает         |
| `variant.py`                                  | пустой ввод              | `[]`, `0`, `0`, `[]`                                                                  | совпадает         |
| `variant.py`                                  | `3 6 9` (без совпадений) | `[]`, `0`, `0`, `[]`                                                                  | совпадает         |
